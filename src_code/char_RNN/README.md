# Char-Level RNN Language Model

This Language Model(LM) uses Recursive Neural Network(RNN) and trained on good nutrition textbooks and cook books from gutenberg.com.

* Food and Flavor: A Gastronomic Guide to Health and Good Living by Henry T. Finck
* The Golden Age Cook Book by Henrietta Latham Dwight
* The Care and Feeding of Children by L. Emmett Holt
